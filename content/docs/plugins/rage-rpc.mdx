# rage-rpc

`rage-rpc` installs `mp.rpc`, a drop-in RPC API based on the [leonardssh/rage-rpc](https://github.com/leonardssh/rage-rpc) port.

<Cards>
  <Card title="Side" icon={<Route />}>Server, client, and CEF/NUI</Card>

## Register and call

<Tabs items={["Server", "Client", "CEF / NUI"]}>
<Tab value="Server">

```js title="server/index.js"
mp.rpc.register('bank:getBalance', async (args, { player }) => {
  if (!player) return 0;

  return await db.balance(player.id);
});
```

</Tab>
<Tab value="Client">

```js title="client/index.js"
const balance = await mp.rpc.callServer('bank:getBalance');
mp.gui.chat.push(`Balance: $${balance}`);
```

</Tab>
<Tab value="CEF / NUI">

```js title="ui/index.js"
const balance = await mp.rpc.callServer('bank:getBalance');
document.querySelector('#balance').textContent = balance;
```

</Tab>
</Tabs>

## API surface

```ts
mp.rpc.register(name, handler)
mp.rpc.unregister(name)
mp.rpc.call(name, args?)
mp.rpc.callServer(name, args?)
mp.rpc.callClient(player, name, args?)
mp.rpc.callBrowser(browser, name, args?)
mp.rpc.callBrowsers(name, args?)
mp.rpc.on(name, handler)
mp.rpc.off(name, handler)
mp.rpc.trigger(name, args?)
mp.rpc.triggerServer(name, args?)
mp.rpc.triggerClient(player, name, args?)
mp.rpc.triggerBrowser(browser, name, args?)
mp.rpc.triggerBrowsers(name, args?)
mp.rpc.setDebugMode(true)
```

## Debugging

```js title="server/debug-rpc.js"
mp.rpc.setDebugMode(true);
```

Use debug mode while porting. Turn it off in production to avoid noisy logs.

## Disable it

```lua title="fxmanifest.lua"
disable_plugin 'rage-rpc'
```

<Accordions>
  <Accordion title="When should I disable rage-rpc?">
    Disable it if your gamemode already ships an RPC system and you do not want duplicate handlers or conflicting global APIs.
  </Accordion>
  <Accordion title="Does it work from browser pages?">
    Yes. Pages loaded through the bridge's browser runtime get `mp.rpc` alongside `mp.events.add()` and `mp.trigger()`.
  </Accordion>
</Accordions>
