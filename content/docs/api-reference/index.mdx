## Type Definition Files

Use these files as authoritative API surfaces:

- `packages/server/types/index.d.ts`
- `packages/client/types/index.d.ts`
- `packages/cef/types/index.d.ts`

## What You Get

- pool/entity signatures
- event manager methods
- procedure call signatures
- world/config/network methods
- GUI/browser/voice/game interfaces

## Recommendation

When uncertain about exact method signatures or overloads, check the type files before implementing gameplay logic.
