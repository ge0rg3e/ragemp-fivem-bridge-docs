---
title: Convars and Security
description: Runtime convars that control ingress rate limits and remote execution behavior.
---

## Security-Related Convars

- `ragemp_allow_remote_eval` (default `0`)
- `ragemp_allow_remote_invoke` (default `0`)
- `ragemp_ingress_rate_limit` (default `100` events/sec per source/event)

## Example Safe Defaults

```ini
setr ragemp_allow_remote_eval 0
setr ragemp_allow_remote_invoke 0
setr ragemp_ingress_rate_limit 100
```
